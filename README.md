# 🎯 堂主定时

一款适用于 Windows 的定时鼠标点击工具。设置指定日期和时间，到达目标时间后，自动在指定屏幕坐标执行鼠标单击或双击。

## ✨ 功能特性

- ⏰ **精准定时**：根据电脑系统时间执行任务，可指定日期和具体时分秒。
- 🖱️ **多种鼠标操作**：支持左键、右键、中键，以及单击和双击。
- 🎯 **坐标选择**：通过桌面截图选择目标位置，也可以手动输入 X、Y 坐标。
- ⏳ **实时倒计时**：显示距离任务执行的剩余时间。
- ⏸️ **暂停与继续**：可以暂停任务，并在需要时继续倒计时。
- ❌ **取消任务**：支持随时取消尚未执行的任务。
- 🧪 **测试点击**：开始定时前，可以立即测试点击位置和操作方式。
- 🎨 **自定义图标**：程序使用「堂主定时」专属图标。
- 📦 **独立 EXE**：支持打包为 Windows 可执行文件，无需每次手动运行 Python 源码。

## 🚀 使用教程

### 1. 启动软件

双击运行 `堂主定时.exe`。

如果 Windows 弹出安全提示，请先确认程序来源可信，再决定是否运行。

### 2. 设置触发时间

在软件中填写：

- **日期**：格式为 `YYYY-MM-DD`
- **时间**：格式为 `HH:MM:SS`

例如：

```text
日期：2026-10-25
时间：14:30:00
```

软件使用电脑当前的系统时间进行倒计时。请确保系统日期和时间准确，并将目标时间设置为未来时间。

### 3. 选择点击位置

有两种方式：

- **选择屏幕位置**：打开桌面截图，单击目标位置记录坐标。
- **手动输入**：直接填写 X、Y 坐标。

建议先选择位置，再使用「测试点击」确认目标是否正确。

### 4. 设置鼠标操作

选择需要执行的鼠标按键：

- 左键
- 右键
- 中键

再选择操作方式：

- 单击
- 双击

### 5. 开始定时任务

点击「开始定时」，软件会显示实时倒计时。

任务执行前，可以使用「暂停」或「取消任务」控制任务。

到达设定时间后，软件会在指定坐标执行相应操作。执行成功后，程序会自动关闭。

## 💻 运行环境

- 操作系统：Windows 10 / Windows 11
- Python 源码运行：建议使用 Python 3.10 或更新版本
- 依赖库：`pyautogui`、`Pillow`
- EXE 打包工具：`PyInstaller`

## 🛠️ 从源码运行

如果你希望直接运行 Python 源码：

1. 安装 Python。
2. 下载或克隆本项目。
3. 打开终端，进入项目文件夹。
4. 安装依赖：

```bash
python -m pip install pyautogui pillow
```

5. 运行程序：

```bash
python 堂主定时.py
```

## 📦 从源码打包 EXE

先安装打包依赖：

```bash
python -m pip install pyautogui pillow pyinstaller
```

然后在项目文件夹中执行：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "堂主定时" --icon "icon.ico" --add-data "icon.ico;." "堂主定时.py"
```

打包完成后，可以在 `dist` 文件夹中找到：

```text
dist/堂主定时.exe
```

请确保 `堂主定时.py` 和 `icon.ico` 位于项目文件夹中。

## ⚠️ 注意事项

1. **时间准确性**：软件依据电脑系统时间执行任务。系统时间不准确可能导致执行时间偏差。
2. **点击位置**：请在任务开始前确认坐标正确，避免点击到错误的按钮或区域。
3. **前台与后台程序**：自动点击通常会影响目标坐标处当前可交互的窗口。请确保执行时目标窗口处于合适状态。
4. **屏幕变化**：如果分辨率、显示缩放或窗口布局发生变化，原有坐标可能不再准确。
5. **安全使用**：请勿用于未经授权的操作，也不要在可能造成损失的关键界面上未经测试就执行自动点击。
6. **杀毒软件提示**：自动化工具打包成 EXE 后可能触发部分安全软件的误报。请通过可信的源码和构建过程核实程序，不要盲目忽略安全警告。

## ❓ 常见问题

### Q：为什么程序没有按预期点击？

请检查电脑系统时间、目标日期和时间、坐标值，以及目标窗口是否处于正确位置。

### Q：为什么点击到了错误的位置？

请重新使用「选择屏幕位置」记录坐标，并通过「测试点击」确认结果。调整分辨率或显示缩放后也可能需要重新选择。

### Q：运行源码时提示缺少模块怎么办？

执行以下命令安装依赖：

```bash
python -m pip install pyautogui pillow
```

如果电脑上安装了多个 Python 版本，请使用运行程序时对应的 Python 环境安装依赖。

### Q：可以设置双击吗？

可以。在「点击方式」中选择「双击」即可。

### Q：任务执行成功后程序会一直运行吗？

不会。根据当前版本的设计，任务执行成功后程序会自动关闭。
